About Me

Self-taught mobile developer based in Lincoln, UK — the kind who learned by breaking things until they worked. I've built apps for prisons, smart key systems, my wife's business, and whatever weird idea keeps me up at 2am. Swift is my weapon of choice, but I speak fluent Kotlin too. If it ships to an App Store, I've probably done it.

eLOQ

BLE smart key system

Originally built whilst employed at Dynamic Access Solutions using Java and Objective-C. eLOQ is an intelligent access control system used across retail, education, healthcare, and industrial sectors. I collaborated directly with Chinese manufacturers' engineers to integrate their SDKs, enabling smart key programming with full audit trails. Recently returned as a contractor to migrate both apps to modern Kotlin and Swift.
